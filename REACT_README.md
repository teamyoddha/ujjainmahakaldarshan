# Ujjain Mahakal Darshan

This is a React website using the supplied orange and blue logo. Design and page components are in src/. The homepage and five linked resource pages have independent URLs.

## Preview and build

- Included preview: run `npx serve dist` from the project directory and open the printed URL. The included preview loads pinned React packages from esm.sh and Wikimedia destination photos, so it needs internet access.
- Production: run `npm install` and then `npm run build`. This creates a self-contained local React bundle. Upload the contents of dist/ to a staging web root and verify the site before replacing the existing homepage. Wikimedia photos still load remotely. Credits are on photo-credits.html.
- The site currently uses enquiry-only service language. Review the draft business policies and add an owner-approved cancellation and refund policy if deposits or payments are accepted.
